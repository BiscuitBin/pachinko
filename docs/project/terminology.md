# Terminology

This page will be the glossary seed: the words this repository uses precisely and the
one meaning each carries. It starts with repository, library, service, effect, effect
trait, fake, specification and gate, and it holds no domain words, because the
specifications have not defined a domain yet. When they do, their vocabulary is stated
there and this page points at it. Lane T07 writes it.
