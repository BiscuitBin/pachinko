# Purpose and scope

This page will say what the foundation is and what it is not. It is a Cargo workspace
of two crates, a std library and a minimal service binary built around it, carrying the
toolchain, gates, handbook and agent contract so that the specifications and the code
arrive in a repository that is already green. It will name the non-goals plainly: no
domain yet, no runtime or transport for the service, and nothing published to a
registry. It will also say who consumes the library. Lane T07 writes it.
