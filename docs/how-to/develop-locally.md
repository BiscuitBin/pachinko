# Develop locally

This guide will cover setting up a working copy and the daily loop: installing the
pinned toolchain and the tools the gate needs, running `just initialize`, editing either
of the two crates, and running the focused recipes before the full gate. It follows the
same routine as the repository it was adapted from, with two crates in place of one.
Lane T07 writes it.
