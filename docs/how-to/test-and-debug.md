# Test and debug

This guide will show how to run and narrow the tests: nextest filters for one crate or
one test, the integration test that runs the built service binary, doctests, and the
coverage report rendered as HTML so a missing line can be found and read. It will also
say how to debug a failure the gate reports. Lane T07 writes it.
