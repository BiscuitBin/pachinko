# Deploy to GitHub Pages

This guide will cover publishing the API reference: building the rustdoc for both
crates, assembling the site with `just site`, and the workflow that deploys it to the
GitHub Pages URL of this repository. It will also say how to check a deployment and what
to do when one fails. Lane T07 writes it.
