# Work with the specifications

This guide will explain how to read, change and check the Allium specifications under
`docs/specs/`: the module table, which today lists one placeholder root module that
states no behaviour, the `just check-specs` and `just analyse-specs` recipes, and the
waiver terms quoted verbatim. It will describe how a specification change comes before
the code that implements it. Lane T06 writes it.
