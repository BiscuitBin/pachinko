# Make your first change

This tutorial will take a newcomer from a fresh clone to a green gate through one small
change that can be followed again at any time. The exercise changes the line the
service's `run()` writes, watches its unit test and the test that runs the built binary
both fail, updates the two of them, and finishes with `just check` passing. Lane T07
writes it once the service and its tests are in their final shape.
