# Quality philosophy

This page will give the argument behind the gate: why each check exists, what failure
it is there to catch, and why the whole gate runs on every change rather than only in
continuous integration. It keeps the reasoning of the repository it was adapted from
and draws its examples from the gates this repository runs. Lane T07 writes it.
