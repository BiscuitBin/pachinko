# Specifications

This page will explain why behaviour is written down in Allium before it is built, and
why the specifications are the source of truth when they and the code disagree. It will
say that there is one module today, the placeholder root, and that it states no
behaviour yet, so every behaviour the code gains arrives first as a specification
change. Lane T06 writes it.
