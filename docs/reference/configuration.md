# Configuration

This page will describe each configuration file and what it controls: both crate
manifests and the workspace manifest, the lint table, `deny.toml`, the coverage floor,
the pixi manifest, the two tool lists and the script that checks the effects boundary.
For each setting it will say why it has the value it has. Lane T07 writes it.
