# Commands

This page will list every `just` recipe in a table: what it runs, whether it reaches the
network, and whether `just check` includes it. The table follows the Justfile exactly,
so a reader can find the recipe behind any gate without opening the file, and it notes
the recipes that sit outside the gate, such as the audit and the site build. Lane T07
writes it.
