# Documentation contract

This page will state the rules every handbook page obeys: registration in the manifest,
frontmatter that agrees with it, one owner for each topic, links that resolve, and every
page reachable from the map. Its section on links that leave the repository will name
only the outward pages that exist here. Lane T07 writes it, keeping the rules of the
repository it was adapted from verbatim.
