# Troubleshooting

This page will collect the failures people meet and how to clear each one: a toolchain
that does not match the pin, a stale tool, a hook that cannot find its binary, a gate
that fails only offline. It keeps the entries of the repository it was adapted from
that apply to the targets this repository builds and drops the rest. Lane T07 writes it.
