# Maintenance

This page will set out the maintenance routine: bumping the pinned toolchain
deliberately, refreshing the tool lists and the pixi lock, reviewing audit results, and
keeping the handbook in step with the code. It follows the routine of the repository it
was adapted from, and says how often each task falls due and which recipe performs it.
Lane T07 writes it.
